---
name: Search discovery prompts
description: User constraints and catalog-grounding rules for rotating search ideas.
---

Rotating search prompts on this site must use only places, people, and references, not colors.

**Why:** The user explicitly said, “dont use any colors only places people and refrences,” when asking for extensive, unique, niche search ideas grounded in the available catalog.

**How to apply:** Curate artists, cities, crews, labels, songs, albums, and cultural or screen references. Do not add color or garment/product-type suggestions to the rotation.

Rotate search ideas every three seconds.

**Why:** The user explicitly requested a three-second rotation.

**How to apply:** Keep the full rotation, including the typewriter transition, within that cadence rather than adding transition time after a three-second hold.

Use prompts that return results when searched exactly as shown, and vary the first idea rather than always opening with the same city.

**Why:** Discovery prompts should help visitors find real catalog options. Familiar alternative spellings and multi-concept phrases can return no results under the existing literal shop search.

**How to apply:** Check new ideas against the shop's searchable grouped product fields and available fits. Keep prompt generation lightweight and independent of runtime full-catalog loading.
