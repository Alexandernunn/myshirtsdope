---
name: Explicit product choices
description: Merchant requirement for deliberate size and color confirmation before adding products to cart.
---

Shoppers must explicitly choose both size and color before either product-page Add to Cart button can add an item. An initial product preview, including a variant link, is not consent to purchase its size or color.

**Why:** The merchant requested mandatory size and color choices and guidance to those options when shoppers try to add too early.

**How to apply:** Keep preview defaults separate from deliberate choices. Both Add to Cart locations must guide shoppers to missing choices without adding an item. Reset confirmation when changing the product or fit, and never silently confirm a replacement option.
